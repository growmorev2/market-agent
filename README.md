# മാർക്കറ്റ് ഏജന്റ് 📊

എല്ലാ ട്രേഡിംഗ് ദിവസവും വൈകിട്ട് നിങ്ങളുടെ GM World ബ്രെഡ്ത്ത് നോക്കി മാർക്കറ്റ് അവസ്ഥ (🟢🟡🔴) കണ്ടെത്തി, Chartink സ്കാനറുകൾ ഓടിച്ച്, ഓരോ സ്റ്റോക്കിന്റെയും സെക്ടർ കണ്ടെത്തി, AI ഉപയോഗിച്ച് മലയാളത്തിൽ ഒരു വിശകലന റിപ്പോർട്ട് എഴുതി, ശനിയാഴ്ച രാവിലെ ഒരു ആഴ്ച റാപ്പപ്പും ഉണ്ടാക്കി, **Telegram**, **Discord**, **വെബ്‌പേജ് (GitHub Pages)** എന്നീ മൂന്നിടത്തേക്കും അയക്കുന്ന ഏജന്റ്. മുഴുവനും GitHub-ൽ സൗജന്യമായി ഓടും, കമ്പ്യൂട്ടർ ഓൺ ആക്കി വെക്കേണ്ട.

> ⚠️ ഇത് വിവരങ്ങൾ വിശകലനം ചെയ്ത് തരും. വാങ്ങണോ വിൽക്കണോ എന്ന് പറയില്ല — ആ തീരുമാനം നിങ്ങളുടേതാണ്.

## ഭാഗം 1: ഇത് എങ്ങനെ പ്രവർത്തിക്കുന്നു

```

   │
   ├─ 0. GM World ബ്രെഡ്ത്ത് → മാർക്കറ്റ് അവസ്ഥ 🟢🟡🔴 ... lib/breadth.py
   ├─ 1. Chartink സ്കാനറുകൾ ഓടിക്കും ........ lib/chartink.py
   ├─ 2. സെക്ടർ ചേർക്കും, ഇന്നലത്തേതുമായി താരതമ്യം ... lib/sectors.py
   ├─ 3. AI വിശകലനം + വാർത്ത തിരഞ്ഞ് കാരണം: Gemini → Groq ... lib/ai.py
   ├─ 4. വെബ്‌പേജ് ഉണ്ടാക്കും ................ lib/site.py
   └─ 5. Telegram + Discord-ലേക്ക് അയക്കും .... lib/notify.py

GitHub (ശനിയാഴ്ച രാവിലെ 9:13)
   │
   ├─ 1. ആഴ്ചയിലെ ദിവസേനയുള്ള ഹിസ്റ്ററി ചേർക്കും ... lib/weekly.py
   ├─ 2. AI ആഴ്ച വിശകലനം
   └─ 3. വെബ്‌പേജ് + Telegram + Discord
```

ഓട്ടോമേഷനും ഏജന്റും തമ്മിലുള്ള വ്യത്യാസം ഇവിടെ കാണാം: ഘട്ടം 1, 2, 4, 5 ഓട്ടോമേഷൻ ആണ് (എല്ലാ ദിവസവും ഒരേ പണി). ഘട്ടം 3-ൽ AI ഡാറ്റ വായിച്ച്, എന്താണ് പ്രധാനം എന്ന് സ്വയം തീരുമാനിച്ച് എഴുതുന്നു — അതാണ് "ഏജന്റ്" ഭാഗം.

## ഭാഗം 2: സെറ്റപ്പ് (ഏകദേശം 30 മിനിറ്റ്)

ഓരോ ഘട്ടത്തിലും കിട്ടുന്ന key/ലിങ്ക് ഒരു നോട്ടിൽ കുറിച്ചുവെക്കുക. **ഇവ ആരുമായും പങ്കുവെക്കരുത്.**

### ഘട്ടം 1 — GitHub repo ഉണ്ടാക്കുക

1. github.com-ൽ **New repository** → പേര്: `market-agent`
2. **Public** തിരഞ്ഞെടുക്കുക (സൗജന്യ GitHub Pages-ന് public വേണം. റിപ്പോർട്ട് വെബ്‌പേജ് ലിങ്ക് അറിയുന്ന ആർക്കും കാണാം; API key-കൾ secret ആയതിനാൽ ആർക്കും കാണാനാകില്ല)
3. ഈ ഫോൾഡറിലെ എല്ലാ ഫയലുകളും upload ചെയ്യുക. കമ്പ്യൂട്ടറിൽ നിന്ന് ചെയ്യുന്നതാണ് എളുപ്പം:
   ```bash
   cd market-agent
   git init && git add . && git commit -m "first"
   git branch -M main
   git remote add origin https://github.com/<നിങ്ങളുടെ-username>/market-agent.git
   git push -u origin main
   ```
   (`.github` ഫോൾഡർ മറഞ്ഞിരിക്കുന്ന ഫോൾഡറാണ്; അത് upload ആയെന്ന് ഉറപ്പാക്കുക.)

### ഘട്ടം 2 — Gemini API key (സൗജന്യം)

1. **aistudio.google.com** → Google അക്കൗണ്ടിൽ ലോഗിൻ
2. **Get API key** → **Create API key**
3. കിട്ടുന്ന key കോപ്പി ചെയ്യുക → ഇത് `GEMINI_API_KEY`

### ഘട്ടം 3 — Groq API key (സൗജന്യം, ബാക്കപ്പ്)

1. **console.groq.com** → സൈൻ അപ്പ്
2. **API Keys** → **Create API Key**
3. കോപ്പി ചെയ്യുക → ഇത് `GROQ_API_KEY`

### ഘട്ടം 4 — Telegram bot

1. Telegram-ൽ **@BotFather** തിരയുക → `/newbot` അയക്കുക
2. bot-ന് ഒരു പേരും, `_bot`-ൽ അവസാനിക്കുന്ന username-ഉം കൊടുക്കുക (ഉദാ: `dipin_market_bot`)
3. BotFather ഒരു **token** തരും → ഇത് `TELEGRAM_BOT_TOKEN`
4. നിങ്ങളുടെ പുതിയ bot തുറന്ന് **Start** അമർത്തി, "hi" എന്ന് ഒരു മെസേജ് അയക്കുക
5. ബ്രൗസറിൽ ഈ ലിങ്ക് തുറക്കുക (TOKEN-ന് പകരം നിങ്ങളുടെ token):
   `https://api.telegram.org/botTOKEN/getUpdates`
6. അതിൽ `"chat":{"id":123456789` എന്ന് കാണാം → ആ നമ്പർ `TELEGRAM_CHAT_ID`

### ഘട്ടം 5 — Discord webhook

1. Discord-ൽ ഇടതുവശത്തെ **+** → **Create My Own** → ഒരു server ഉണ്ടാക്കുക (ഉദാ: "Trading")
2. ഒരു text ചാനൽ ഉണ്ടാക്കുക, ഉദാ: `#daily-report`
3. ചാനലിന്റെ ⚙️ **Edit Channel** → **Integrations** → **Webhooks** → **New Webhook**
4. **Copy Webhook URL** → ഇത് `DISCORD_WEBHOOK_URL`

### ഘട്ടം 6 — Key-കൾ GitHub-ൽ secret ആയി ചേർക്കുക

repo-യിൽ **Settings** → **Secrets and variables** → **Actions** → **New repository secret**. ഈ അഞ്ചെണ്ണം ഓരോന്നായി ചേർക്കുക (പേര് കൃത്യമായി ഇങ്ങനെ തന്നെ):

| Name | Value |
|---|---|
| `GEMINI_API_KEY` | ഘട്ടം 2 |
| `GROQ_API_KEY` | ഘട്ടം 3 |
| `TELEGRAM_BOT_TOKEN` | ഘട്ടം 4.3 |
| `TELEGRAM_CHAT_ID` | ഘട്ടം 4.6 |
| `DISCORD_WEBHOOK_URL` | ഘട്ടം 5.4 |

ഏതെങ്കിലും ഒന്ന് ഇല്ലെങ്കിലും ഏജന്റ് ഓടും — ആ ഭാഗം മാത്രം ഒഴിവാക്കും.

### ഘട്ടം 7 — GitHub Pages ഓൺ ചെയ്യുക

1. repo **Settings** → **Pages**
2. **Source**: *Deploy from a branch*
3. **Branch**: `main`, ഫോൾഡർ: `/docs` → **Save**
4. കുറച്ച് മിനിറ്റിന് ശേഷം നിങ്ങളുടെ സൈറ്റ്: `https://<username>.github.io/market-agent/`

### ഘട്ടം 8 — ആദ്യ പരീക്ഷണം

1. repo-യിൽ **Actions** ടാബ് → **Daily Market Agent** → **Run workflow**
2. 1–2 മിനിറ്റ് കാത്തിരിക്കുക. പച്ച ✅ വന്നാൽ Telegram-ഉം Discord-ഉം നോക്കുക
3. ചുവപ്പ് ❌ വന്നാൽ അതിൽ ക്ലിക്ക് ചെയ്ത് **Run agent** ഘട്ടം തുറന്ന് പിശക് വായിക്കുക (താഴെ "പ്രശ്നങ്ങൾ" കാണുക)

> ആദ്യ ദിവസം "പുതിയ സ്റ്റോക്കുകൾ" ഉണ്ടാകില്ല — താരതമ്യം ചെയ്യാൻ ഇന്നലത്തെ ഡാറ്റ വേണം. രണ്ടാം ദിവസം മുതൽ കാണിക്കും.

## ഭാഗം 3: മാറ്റങ്ങൾ വരുത്താൻ

### സ്കാനർ ചേർക്കാൻ / മാറ്റാൻ — `scans.json`

ഇപ്പോൾ നാല് സ്കാനറുകൾ ഉണ്ട്: **HOLYGRAIL**, **MULTIBAGGER**, **ROE/EPS IMPROVING**, **GM Universe**. നാലിന്റെയും scan clause നിങ്ങളുടെ `chartink_scan.py`-ൽ നിന്ന് അതേപടി എടുത്തതാണ്, അതുകൊണ്ട് ഏജന്റിനും നിങ്ങളുടെ വാച്ച്‌ലിസ്റ്റ് സ്ക്രിപ്റ്റിനും ഒരേ റിസൾട്ട് കിട്ടും.

```json
{
  "name": "എന്റെ പുതിയ സ്കാൻ",
  "slug": "my-new-scan",
  "about": "AI-ക്ക് മനസ്സിലാക്കാൻ ഒരു ചെറിയ വിവരണം (ഇംഗ്ലീഷിൽ)",
  "clause": "( {cash} ( ... ) )",
  "max_show": 50
}
```

- `clause`: Chartink സ്കാനറിലെ scan clause. ഇത് ഉണ്ടെങ്കിൽ `slug` ഒരു പേര് മാത്രമാണ് (മാറ്റരുത്, ഹിസ്റ്ററിയും ട്രാക്കറും ഇതുവെച്ചാണ്)
- `clause` ഇല്ലെങ്കിൽ `slug` Chartink ലിങ്കിലെ `/screener/` കഴിഞ്ഞുള്ള ഭാഗം ആയിരിക്കണം; ഏജന്റ് പേജിൽ നിന്ന് clause കണ്ടെത്താൻ ശ്രമിക്കും
- `max_show` (ഇഷ്ടമുണ്ടെങ്കിൽ): വലിയ ലിസ്റ്റുകൾക്ക് വെബ്‌പേജിൽ എത്ര സ്റ്റോക്ക് കാണിക്കണം. GM Universe-ന് 50 ആണ് (പുതിയവ ആദ്യം)
- Chartink-ൽ ഒരു സ്കാനർ മാറ്റിയാൽ ഇവിടത്തെ `clause`-ഉം മാറ്റണം; വാച്ച്‌ലിസ്റ്റ് സ്ക്രിപ്റ്റിലും

### മാർക്കറ്റ് അവസ്ഥ സിഗ്നൽ 🟢🟡🔴

### നീക്കത്തിന്റെ കാരണങ്ങൾ (Why it moved)

ദിവസേനയുള്ള റിപ്പോർട്ടിൽ "എന്തുകൊണ്ട് നീങ്ങി" എന്നൊരു ഭാഗം ഉണ്ടാകും. ഏജന്റ് ഇവയ്ക്ക് കാരണം തിരയും:

- രണ്ടിലധികം സ്കാനറിൽ വന്ന സ്റ്റോക്കുകൾ, പുതുതായി വന്നവ, ഏറ്റവും കൂടുതൽ നീങ്ങിയവ (പരമാവധി 10)
- മുന്നിലുള്ള 3 സെക്ടറുകൾ

AI ഇന്റർനെറ്റിൽ പുതിയ വാർത്ത തിരഞ്ഞ് ഓരോന്നിനും ഒരു വരിയിൽ കാരണം എഴുതും (ലിങ്ക് ഇല്ലാതെ, കാരണം മാത്രം). വ്യക്തമായ വാർത്ത കിട്ടിയില്ലെങ്കിൽ അങ്ങനെ തന്നെ പറയും, ഊഹിക്കില്ല. ആഴ്ച റാപ്പപ്പിലും സെക്ടർ റൊട്ടേഷന്റെയും സ്ഥിരമായി നിന്ന സ്റ്റോക്കുകളുടെയും കാരണം ഉണ്ടാകും.

ഏതെങ്കിലും ദിവസം വാർത്ത തിരയൽ പരാജയപ്പെട്ടാൽ (സൗജന്യ പരിധി കഴിഞ്ഞാൽ), റിപ്പോർട്ട് കാരണങ്ങളില്ലാതെ വരും, അടിയിൽ "കാരണങ്ങൾ ഇന്ന് ലഭ്യമായില്ല" എന്ന് കാണിക്കും.

> AI കണ്ടെത്തുന്ന കാരണങ്ങൾ ചിലപ്പോൾ തെറ്റാകാം. പ്രധാനപ്പെട്ട തീരുമാനങ്ങൾക്ക് മുമ്പ് വാർത്ത സ്വയം ഒത്തുനോക്കുക.

### സമയം മാറ്റാൻ — `.github/workflows/daily-agent.yml`, `weekly-wrap.yml`

```yaml
- cron: "17 11 * * 1-5"
```
സമയം **UTC**-യിലാണ്. IST-ൽ നിന്ന് 5 മണിക്കൂർ 30 മിനിറ്റ് കുറയ്ക്കുക:

| വേണ്ട IST സമയം | cron |
|---|---|
| രാവിലെ 8:15 | `"45 2 * * 1-5"` |
| വൈകിട്ട് 4:47 | `"17 11 * * 1-5"` |
| വൈകിട്ട് 6:13 (ഇപ്പോൾ) | `"43 12 * * 1-5"` |

ആഴ്ച റാപ്പപ്പ് `weekly-wrap.yml`-ൽ `"43 3 * * 6"` (ശനി 9:13 AM). അവസാന അക്കം ദിവസം: 0 = ഞായർ, 6 = ശനി.

GitHub ചിലപ്പോൾ 5–20 മിനിറ്റ് വൈകി ഓടിക്കും; അത് സാധാരണമാണ്. GM World 5:30 PM-ന് ആണ് പുതുക്കുന്നത്, അതുകൊണ്ട് ദിവസേനയുള്ള റൺ 6 മണിക്ക് മുമ്പ് ആക്കിയാൽ മിക്ക ദിവസവും ഇന്നലത്തെ ബ്രെഡ്ത്ത് ആയിരിക്കും കിട്ടുക.

### 📋 Stock selection strategy (Momentum / Value)

എല്ലാ ദിവസവും രണ്ട് portfolio-ക്കായി സ്റ്റോക്കുകൾ ഫിൽറ്റർ ചെയ്ത് `docs/strategy.html` എന്ന പേജിൽ കാണിക്കും (Buy ready / Watch / Model portfolio / Exit). Telegram റിപ്പോർട്ടിൽ ഒരു ചെറിയ സംഗ്രഹവും ലിങ്കും.

- **Momentum:** GM Universe ∩ Top MSWING (ആദ്യ 100) → Stable rank, Trend (Close > 50 > 200 DMA), Not extended (20 EMA-യിൽ നിന്ന് ≤15%), റിസൾട്ട് 7 ദിവസത്തിൽ ഇല്ല, Strong sector. Exit: 50 DMA-ക്ക് താഴെ 2 ദിവസം / 3 ദിവസം Top 100-ൽ ഇല്ല / 10% stop-loss.
- **Value:** ROE/EPS IMPROVING → Stable in scanner, Above 200 DMA, Near 200 DMA (≤20%), Margin of safety ≥20% (valuation ഉള്ളപ്പോൾ). Exit: intrinsic value എത്തി / 200 DMA-ക്ക് 10% താഴെ / 3 ദിവസം സ്കാനറിൽ ഇല്ല.
- **Market status gate:** Stay out / Failed turn / Wait-ൽ Momentum entry ഇല്ല; Bottoming / Early rally-യിൽ പരമാവധി 3.
- Model portfolio `data/strategy.json`-ൽ. വില Yahoo Finance-ൽ നിന്ന് (1 വർഷം).
- Valuation: `data/valuations.json` = `{"SYMBOL": intrinsic_value}` ചേർത്താൽ Margin of safety ഫിൽറ്റർ ഓണാകും.
- അക്കങ്ങൾ മാറ്റാൻ: `lib/strategy.py`-ലെ `CFG`, `GATE`.

#### Value portfolio-ക്ക് Fair Value ബന്ധിപ്പിക്കാൻ (ഒറ്റത്തവണ)

Fair Value നിങ്ങളുടെ private `screener-summery` repo-യിലെ `output/valuations.json`-ൽ നിന്നാണ് (Valuation sheet-ലെ Fair Value). ആ repo വായിക്കാൻ ഒരു read-only token വേണം:

1. github.com → പ്രൊഫൈൽ ചിത്രം → **Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**
2. Name: `market-agent-read` · Expiration: 1 വർഷം · **Repository access → Only select repositories → screener-summery**
3. **Permissions → Repository permissions → Contents → Read-only** → **Generate token** → token കോപ്പി ചെയ്യുക (ചാറ്റിൽ ഒട്ടിക്കരുത്)
4. market-agent repo → **Settings → Secrets and variables → Actions → New repository secret** → Name `SCREENER_TOKEN`, Value: token → **Add secret**

Fair Value നമ്പറുകൾ ഈ public repo-യിലോ strategy പേജിലോ വരില്ല — "Margin of safety" ✓/✗ മാത്രം. Token ഇല്ലെങ്കിൽ Value portfolio ROE/EPS + 200 DMA മാത്രം വെച്ച് ഓടും.
